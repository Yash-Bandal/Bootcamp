Question 1:
Design a RESTful API for a Task Management System 

1. Endpoints for registering users, updating their profiles, and managing authentication (e.g., login, logout).

Controller - UsersController

A. Register User

> Method and Endpoin : POST /api/auth 
> Method and Endpoint : POST /api/users

> Request Body
{
"name" : "Yash",
"email" : "yb@gdeltax.com",
"password" : "strongP"
}

> Response Status Code : 201 Created

Reason - 
 POST /api/auth - Used when, user is added directly at Register time
 POST /api/users - Used when, example, a admin wants to add a complete new user, with all details



B. Update Profiles

> Method and Endpoint : PATCH /api/users/{userId}

> Request Body
{
"name" : "Yash Bandal",
"email" : "yb@gdeltax.com",
}

> Response Status Code : 200 Ok

Description - Here, we are just updating the name and email of the Profile, 
not the entire Profile resource, thus PATCH is used for updation.

PUT will be appropriate when the complete resource is being replaced/updated.

C. Manage Authenticaion

C.1
Login

> Method and Endpoint : POST /api/auth/login

> Request Body
{
"email" : "yb@gdeltax.com",
"password" : "strongP"
}

> Response Body
{
"token" : "JWT_Token"
}

> Response Status Code : 200 OK

C.2
Logout

> Method and Endpoint : POST /api/auth/logout

> Request Body : No body

> Response Status Code : 204 No Content

2. Endpoints to create, retrieve, update, and delete tasks

Controller - TasksController

A. Create Task

> Method and Endpoint : POST /api/tasks

> Request Body
{
"title" : "REST-Assignment-1",
"description" : "Perform API Design Task",
"status" : "pending",
"priority" : "high",
"dueDate" : "2026-09-25",
}

> Response Status Code : 201 Created


B. Retrieve Task

> Method and Endpoint :
 GET /api/tasks
 GET /api/tasks/{taskId}   <- Get task by Id

> Request Body : No Body

> Response Status Code : 200 Ok


C. Update Task

> Method and Endpoint : PATCH /api/tasks/{taskId} 

> Request Body : 
{
"status" : "completed",
"priority" : "high"
}

> Response Status Code : 200 Ok

PUT - Method that is used when we want to update the entire 
column/all attributes of a resource.
PATCH - Method that is used when we want to update a specific cell/field of a column/attribute
without replacing a complete resource.

D. Delete Task

> Method and Endpoint : DELETE /api/tasks/{taskId} 

> Request Body : No Body

> Response Status Code : 204 No Content


------------------------------------------------------------------------------------------------
