Social Media Platform

1. Create a Post

> Endpoint - POST /posts
> Request Body -
  {
  "content": "Having a great day!",
  "imageUrl": "https://example.com/image.jpg"
  }

> Response Body -
  {
  "postId": 101,
  "message": "Post created successfully"
  }

> Response - 201 Created



2. Delete a Post

> Endpoint - DELETE /posts/{postId}
> Response Body -
  {
  "message": "Post deleted successfully"
  }
> Response - 200 OK



3. Comment on a Post
> Endpoint - POST /posts/{postId}/comments
> Request Body -
  {
  "content": "Great post!"
  }

> Response Body -
  {
  "commentId": 501,
  "message": "Comment added successfully"
  }

> Response - 201 Created



4. Like/Unlike a Post

> Endpoint - 
  > Like -> POST /posts/{postId}/likes
  > Dislike -> DELETE /posts/{postId}/likes
> Response Body -
  {
  "message": "Post liked/disliked successfully"
  }
> Response - 200 OK



5. Get all posts for a user
> Endpoint -
Right - GET /posts
Wrong -  GET /users/{userId}/posts

Authorization :- Bearer <token>
> Response Body -
  [
    {
      "postId": 101,
      "content": "Having a great day!",
      "likes": 25,
      "comments": 5

    {
      "postId": 102,
      "content": "Learning REST APIs",
      "likes": 40,
      "comments": 8

  ]

> Response - 200 OK



6. Follow/Unfollow a user

> Endpoint -
Wrong
  > Follow -  POST /users/{userId}/following/{targetUserId}
  > Unfollow - DELETE /users/{userId}/following/{targetUserId}

Right - 
  > Follow -  POST /users/{targetUserId}/following
  > Unfollow - DELETE /users/{targetUserId}/following

> Request Body -
> Response Body -
  {
  "message": "User followed/Unfollowed successfully"
  }
> Response - 200 OK



7. Get followers for a user

> Endpoint - GET /users/{userId}/followers
> Request Body -
> Response Body -
  [
    {
      "userId": 10,
      "name": "Yash"
    },
    {
      "userId": 20,
      "name": "Sourabh"
    }
  ]

> Response - 200 OK

Explanation - It is correct to take userid here as user is the subject here
